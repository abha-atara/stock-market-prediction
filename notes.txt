---------------------------------------------------------------
STEP 5: ADVANCED MODEL TRAINING
---------------------------------------------------------------
Multi-model comparison (on ITC data):
  Model               R2        MAE
  Linear Regression   0.9898    4.03
  Ridge               0.9912    3.70
  Lasso               0.9913    3.70
  ElasticNet          0.9913    3.70
  SVR (Unscaled)     -8.408   162.34  <- FAILED (scale mismatch)
  Bagging (LinReg)    0.9898    4.03

Why SVR failed:
  - Volume is in millions (10M+), price is 200-400
  - SVR uses Euclidean distance - gets completely ruined by scale difference
  - SVR also cannot extrapolate beyond training range (stock prices kept rising)

Bagging/Boosting verdict for ITC:
  - Bagging tested: 50 Linear Regressors -> R2 = 0.9898, same as single LR
  - Linear regression already has near-zero variance, bagging does nothing
  - Boosting not needed: bias is already minimal (MAE ~Rs 4 on Rs 300+ stock)
  - Decision: Keep plain Linear Regression as deployed model

Cross-Validation (TimeSeriesSplit, 5 folds):
  - Applied only to training portion (67% of data)
  - TimeSeriesSplit used so future data never leaks into training fold
  - Models validated: LinReg, Ridge, SVR (scaled), Random Forest, Bagging
  - Mean CV R2 for all linear models > 0.99 (confirms stability)
  - ITC CV R2: 0.9979

Hyperparameter Tuning (GridSearchCV + TimeSeriesSplit):
  SVR parameters searched:
    C: [1, 10, 100]
    epsilon: [0.01, 0.1, 0.2]
    gamma: ['scale', 0.01, 0.1]
  
  Random Forest parameters searched:
    n_estimators: [100, 200]
    max_depth: [None, 10, 20]
    min_samples_split: [2, 5]

Note on GradientBoosting:
  - Tested on HDFC (R2 = 0.9985) but replaced with RandomForest
  - Reason: Python 3.14 + newer sklearn changed the _loss Cython module
  - Pickle fails to load GBR .pkl files on Python 3.14
  - RandomForest gives same accuracy and loads fine
